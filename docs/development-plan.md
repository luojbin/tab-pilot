# TabPilot 后续开发计划

本计划基于当前 `package.json` 的 v1.3.0、PRD §12–14 和源码检查。以下版本划分与候选功能边界是建议，尚不代表发布承诺；用户已确认 v1.2.0 发布上线，相关功能已在 Firefox / Chrome / Edge 三浏览器实测通过。

## 当前基线

- F1–F8 均已有实现：自动分组、配置管理、页面标识、标题规则、中英双语与全局配置。
- core / app / ui / platform 分层清晰，已有双目标构建和后台、内容脚本打包冒烟测试。
- 本次完整测试：133 项通过。配置页打包测试仅编译和解析脚本，未覆盖 DOM 交互；i18n 只有 3 项测试。
- PRD 的自动化统计仍写 131 项，与当前 133 项不一致；开发指南中仍有 v1.1.1 的发布叙述。应在发布收尾时同步文档。
- 用户已确认 v1.2.0 发布上线，相关功能已完成三浏览器实测；以此作为后续开发的稳定基线，无需重复安排 v1.2 验收。

## 阶段一：v1.3 小范围效率增强

当前确定的开发内容为“复制规则”和“分组置前”；标题正则标志位暂不支持，不纳入 v1.3。其他候选功能不自动纳入本版。既有版本的发布验收已完成，不作为新功能开发的前置任务。

### 1. 复制规则（已实现，Firefox 测试通过；Chrome / Edge 待验证）

- 入口：分组列表的 ⋯ 菜单新增“复制”。
- 深拷贝折叠、阈值、备注、页面标识、标题规则与匹配路径，生成新 id；新分组追加到末尾并自动选中，颜色按末尾序号循环取色。
- 名称生成唯一的“原名（副本）/ 原名（副本 2）”。这是用户数据，只在创建时生成，不随界面语言切换改写。
- 匹配路径原样复制，方便小幅修改相似环境地址；副本默认停用，用户按需修改路径并启用后，点击“保存并同步”才生效。
- 验收：副本与原规则没有共享的嵌套对象；重复复制无 id / 名称冲突；复制后不立即保存、不立即争抢标签；中英文菜单齐全。
- 涉及：`ui/options.js`、`ui/i18n.js`、相关 UI / 纯逻辑测试、README 与 PRD。
- 配置格式：不增加字段，不需要递增 schemaVersion。

## 阶段二：交互确认后的候选功能

| 建议顺序 | 功能 | 推荐首版边界 | 实施前需要解决的问题 |
|---|---|---|---|
| 1 | 导入合并 | 保留整份替换入口，新增合并预览；默认保留现有规则，导入项追加到末尾，确认后一次保存同步 | id / 同名冲突如何展示和处理；重复导入是否幂等；全局开关、语言、图标行为建议保留本机值 |
| 2 | 图标操作面板与结果提示（已实现） | 点击图标打开 popup 并自动执行配置动作，结果 3 秒后淡出关闭，提供设置入口 | 待三浏览器实测；后续可扩展面板操作和设置 |
| 3 | 根据手动分组生成规则 | 用户选择分组，预览后生成一条包含多个域名的停用规则；跳过非 HTTP(S) 页面 | 是否含子域名、如何保留端口、与已有覆盖规则和同名分组冲突如何处理；避免把完整 URL 的敏感查询串写入规则 |
| 4 | 分组置前、游离标签置后（已纳入 v1.3 并实现） | 默认关闭；全量同步后各窗口按固定标签、分组、游离标签排序，保留相对顺序 | Firefox 复测通过；Chrome / Edge 待验证；自动归组时不重排 |
| 5 | 更多页面标识样式 | 等具体使用场景明确后再定义样式 | 需要真实需求或视觉方案，避免只增加配置项 |

本阶段各项可以独立发版，不预先承诺全部纳入 v1.4。标题正则标志位保留为未排期候选，暂不支持，不纳入 v1.3；现有无标志位、只替换首个匹配的行为保持不变。

## 随后续改动开展的维护

- UI / i18n 自动化覆盖是维护改进项，随新功能补充相关场景，不单独阻塞 v1.3 开发。英文回归检查界面文案与属性，允许语言名称“中文”和中文用户数据保留。
- 已分组标签在事件处理与手动同步路径上的差异、保存配置后的已有组属性更新，属于源码检查发现的待复现观察项，尚未确认为缺陷。若后续实际使用或相关测试发现问题，再按影响安排修复；不据此改动已验证行为。
- PRD 测试数量和开发指南中的历史版本叙述需要同步，属于文档维护，不需要重新执行 v1.2 发布流程。
- 后续每次改动运行相关测试并重新构建；发布新版本时执行完整检查及与改动相关的三浏览器验证。

## 建议执行顺序与工作量

1. 复制规则：约 0.5–1 个开发日，含相关逻辑验证、UI 检查与中英文文案。
2. 复制规则浏览器验收：检查复制、编辑、保存、放弃修改及导入导出后的行为。
3. 其他候选功能按实际使用需求另行安排，不作为 v1.3 的默认开发内容。

以上为排期估算，不是承诺；若仍按 PRD 每周 3–4 小时投入，应拆成多个 20–40 分钟任务推进，不直接将开发日换算成日历周。

当前进度：已推进 1.3.0 并实现复制规则；用户于 2026-11-20 确认复制功能初步完成、Firefox 测试通过；下一步验证 Chrome / Edge 的复制交互，完成 v1.3 相关验证与收尾。

分组置前已实现：全局 `groupsFirst` 开关默认关闭，随配置保存、导入导出；已补顺序、固定标签保护、窗口隔离、幂等及同步入口测试；Firefox 复测通过，Chrome / Edge 待验证。

Firefox 首轮实测发现游离标签移到末尾时会并入末组；已改为 tabGroups.move 整组前移并补充成员归属保护回归。用户于 2026-11-20 确认 Firefox 修复后不会误入分组，复测通过；Chrome / Edge 待验证。

工具栏反馈已改为 popup：打开后自动请求后台执行当前配置动作，显示结果 3 秒后淡出（300ms）关闭。提供设置入口，鼠标移到设置按钮或键盘交互会取消自动关闭。页内 toast 已移除，不依赖网页注入权限。已补 popup 消息、窗口范围、计时及设置交互测试，待浏览器实测。
