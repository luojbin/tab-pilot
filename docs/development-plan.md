## 本版交付内容

| 功能 | 当前实现 |
|---|---|
| 复制规则 | ⋯ 菜单复制；追加末尾，唯一名称/id，匹配地址与配置深拷贝，颜色按新序号循环分配，默认停用 |
| 规则拖拽排序 | 插入线区分目标前/后，仅修改草稿，保存后改变优先级；保留上移/下移入口 |
| 新增菜单 | 「＋ ▾」提供新建空白规则、从当前窗口分组创建规则 |
| 从窗口生成规则 | 设置页读取所在窗口的原生组，无同名规则时生成草稿；网站 origin 去重，同名原生组合并，跳过不可用页面和未命名组 |
| 图标 popup | 打开即执行配置动作；结果停留 3 秒、300ms 淡出关闭；设置入口交互时取消关闭；不依赖网页注入 |
| Firefox 选项菜单 | 图标右键增加「选项」，仅 Firefox 增加 menus 权限；Chromium 保留默认入口 |
| 分组置前 | 可选；同步后按固定标签、分组、游离标签排列；使用 tabGroups.move 整组前移，不改组成员 |
| 拖入分组补规则 | 可选；仅提示已有规则对应的组；可编辑地址，确认后扩写、去重、保存同步；无对应规则时静默 |
| 严格模式 | 可选；已启用规则对应组内页面导航到范围外的 HTTP/HTTPS 地址时移出，不按数量阈值判断 |
| 全局配置卡片 | 语言、四种图标行为与四个功能开关，统一为两列等尺寸卡片 |
| 移除全局启停 | 删除 UI、运行时暂停判断和暂停反馈；旧 globalEnabled 字段读取/导入时丢弃，保留单条规则启停 |
| 追加导入 | 只追加 rules，忽略文件全局设置；名称冲突使用“-导入”及递增后缀，id 冲突重建；确认后保存同步 |

配置字段默认值：`language=auto`、`clickAction=sync`、`autoUpdateGroupRules=true`、`showActionResult=true`、`groupsFirst=false`、`strictMode=false`。版本号不带 beta 后缀，不使用 version_name。

## 发布前剩余事项

1. Firefox / Chrome / Edge 分别验收新增菜单、拖拽前后插入、复制、保存/放弃及六张卡片的中英文布局。
2. 验证分组置前的固定标签保护、成员不变、相对顺序、窗口隔离及重复执行；覆盖折叠组。
3. 验证拖入补规则：已有规则/纯手动组、完整地址/简写、取消/失败、连续请求、关闭开关后清除角标；旧浏览器自动弹出失败时能点击角标处理。
4. 验证严格模式：同站路径、跨站跳转、重定向、SPA URL 变化、停用规则、固定标签及纯手动组；与手动拖入询问组合使用。
5. 验证替换导入和追加导入：全局设置保留、名称/id 冲突、非法数据、空文件、取消及未保存草稿处理。
6. 验证从窗口生成规则：当前窗口限定、同名规则跳过、原生同名组合并、地址去重和端口保留、生成后保存/放弃、重复生成。
7. 完成当前代码最终回归后，从干净源码执行 npm ci、完整测试、双目标构建及 lint；补齐浏览器版本、系统、商店提交和签名记录。提交与推送由开发者手动执行。

手动拖入后自动弹出 popup 需要 Firefox 149+ / Chromium 127+，项目最低版本仍为 Firefox 140+ / Chromium 116+，低版本使用角标引导点击。配置保持 schemaVersion 1，旧版配置可读取；新导出文件移除了旧版必需的全局开关字段，不能视为已验证向旧版本回退。
