## 本版交付内容

| 功能 | 当前实现 |
|---|---|
| 复制规则 | ⋯ 菜单复制；追加末尾，唯一名称/id，匹配地址与配置深拷贝，颜色按新序号循环分配，默认停用 |
| 规则拖拽排序 | 插入线区分目标前/后，仅修改草稿，保存后改变优先级；保留上移/下移入口 |
| 新增菜单 | 「＋ ▾」提供新建空白规则、从当前窗口分组创建规则 |
| 从窗口生成规则 | 设置页读取所在窗口的原生组，无同名规则时生成草稿；网站 origin 去重，同名原生组合并，跳过不可用页面和未命名组 |
| 图标 popup | 打开即执行配置动作；结果停留 3 秒、300ms 淡出关闭；设置入口交互时取消关闭；不依赖网页注入 |
| Firefox 选项菜单 | 图标右键增加「选项」，仅 Firefox 增加 menus 权限；Chromium 保留默认入口 |
| 分组前置 | 可选；同步、自动归组或分组成员变化后将分组移到前面、游离标签移到后面；使用 tabGroups.move 整组前移，不改组成员 |
| 拖入分组补规则 | 可选；仅提示已有规则对应的组；可编辑地址，确认后扩写、去重、保存同步；无对应规则时静默 |
| 组内严格模式 | 各组默认关闭、独立控制；已启用规则对应组内页面导航到范围外的 HTTP/HTTPS 地址时移出，不按数量阈值判断 |
| 全局配置卡片 | 语言、四种图标行为与三个全局功能开关，统一为两列等尺寸卡片 |
| 移除全局启停 | 删除 UI、运行时暂停判断和暂停反馈；旧 globalEnabled 字段读取/导入时丢弃，保留单条规则启停 |
| 追加导入 | 只追加 rules，忽略文件全局设置；名称冲突使用“-导入”及递增后缀，id 冲突重建；确认后保存同步 |

配置字段默认值：`language=auto`、`clickAction=sync`、`autoUpdateGroupRules=true`、`showActionResult=true`、`groupsFirst=false`；组内字段 `rules[].strictMode=false`。版本号不带 beta 后缀，不使用 version_name。

## 发布前剩余事项

1. Firefox / Chrome / Edge 分别验收新增菜单、拖拽前后插入、复制、保存/放弃及五张全局卡片的中英文布局。
2. 验证分组前置的固定标签保护、成员不变、相对顺序、窗口隔离及重复执行；覆盖折叠组。
3. 验证拖入补规则：已有规则/纯手动组、完整地址/简写、取消/失败、连续请求、关闭开关后清除角标；旧浏览器自动弹出失败时能点击角标处理。
4. 验证严格模式：同站路径、跨站跳转、重定向、SPA URL 变化、停用规则、固定标签及纯手动组；与手动拖入询问组合使用。
5. 验证替换导入和追加导入：全局设置保留、名称/id 冲突、非法数据、空文件、取消及未保存草稿处理。
6. 验证从窗口生成规则：当前窗口限定、同名规则跳过、原生同名组合并、地址去重和端口保留、生成后保存/放弃、重复生成。
7. 完成当前代码最终回归后，从干净源码执行 npm ci、完整测试、双目标构建及 lint；补齐浏览器版本、系统、商店提交和签名记录。提交与推送由开发者手动执行。

手动拖入后自动弹出 popup 需要 Firefox 149+ / Chromium 127+，项目最低版本仍为 Firefox 140+ / Chromium 116+，低版本使用角标引导点击。配置使用 schemaVersion 2，正式 schema 1 直接迁移；新导出文件移除了旧版必需的全局开关字段，不能视为已验证向旧版本回退。

## 未排期内容

- 标题正则标志位：已确定不纳入 1.3，目前仍不支持。
- 更多页面标识样式、popup 内更多操作和设置：待具体需求确认。
- 独立日志页、云同步、账号、Safari、容器/窗口维度规则继续不在范围内。

此前源码检查中关于已分组标签保护、已有组属性更新的疑点仍是待复现观察，不属于已确认缺陷，不改变已有实测结论。

自动折叠已改为入组触发：新建分组或有标签从组外实际移入时按规则折叠；组内活动/后台标签导航、刷新与普通同步不改变现有折叠状态，关闭选项不主动展开。保留显式折叠，已补实时成员、阈值批量及入组失败回归，待浏览器验证。

分组前置时机修复：补上自动新建/归组、阈值批量归组、手动归属变化、创建时已归组及严格模式移出后的处理；按窗口批量整理并读取归组后的实际位置，单纯归属变化不重新匹配规则。回归通过，待浏览器复测。

严格模式已移至分组基础配置：每条规则使用可选 strictMode 字段，缺省 false，该可选字段本身无需 schema 升级（当前整体格式为 2）。旧全局值仅补齐未显式设置的规则，保存移除旧字段；复制保留设置，新建/窗口生成默认关闭，追加导入仅取规则值。已补迁移、组间独立和持久化测试，待浏览器实测。


标题规则已扩展为 titlePattern / urlPattern / replacement，replacement 表示完整的新标题，正则仅判断命中和提取捕获组；模板支持两种来源的捕获组，测试区使用 title + url 结构化用例。schemaVersion 当前为 2，正式 schema 1 在读取及两种导入路径直接迁移；旧捕获引用自动转换为新版带来源模板（新版标题按全标题匹配，旧片段条件需显式补充 .*），保存/导出使用新版格式。已覆盖固定标题的 SPA URL 变化、原标题恢复、过期异步响应及迁移回归；双来源编辑、测试行增删、旧备份导入与浏览器实际导航待三浏览器验收。

标题条件默认整标题匹配，URL 条件也默认完整匹配，不固定追加 .*，占位符提示匹配后续路径、参数等变体时显式添加 .*；显式首尾边界归一化，转义美元符号保留，保存校验、预览和页面运行共用编译逻辑。已补分支、捕获编号、参数后缀和缓存隔离回归。


标签页群组独立开关已实现，默认 true；tabGroup 对象统一管理 enabled / minTabs / collapsed / strictMode，schema 定为 2，直接迁移正式 schema 1。首条匹配归属不受群组开关和阈值影响，低于阈值不继续匹配后续规则；页面标识和重命名独立生效，批量候选不吸收优先规则的标签。关闭群组保留已有原生组，停止规则自动折叠、严格移出和拖入补规则提示。新行为待浏览器验收。
