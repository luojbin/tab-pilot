TabPilot 插件简介

TabPilot 是一个轻量的标签页管理器：按 URL 规则自动把标签页归入分组、给分组上色，并能在页面内显示分组标识、按规则改写标签页标题。纯本地运行，无网络请求、不上传数据。

主要功能
- 自动归组：按 URL 规则把新标签页放进指定分组，并设置颜色、是否折叠。
- 手动补同步：保存配置或点工具栏按钮后，按规则重新处理已打开的标签页。
- 页面内标识：命中分组的页面显示彩色边框和分组名 banner，一眼认出当前环境。
- 标签页改名：用正则改写标题，支持捕获组重排和前缀，并可多行预览。
- 备份恢复：配置可导出 / 导入 JSON，换机器或重装后快速恢复。

规则怎么用
- 一条规则对应一个分组，可以配置多个匹配路径，任意一条命中即归组。
- 分组顺序即优先级；同一窗口内命中数量达到阈值才归组，可以「攒够几个再归组」。
- 匹配路径支持简写（如 localhost、192.168.0.123:3000），保存时自动补全。
- 单条规则和全局开关都可以随时停用。

更多细节
- 页面内标识支持上下左右边框和四边 / 四角 banner，宽度、尺寸、字号、透明度可调。
- 标签页名规则按顺序匹配、命中第一条即停止，支持 $1、$<name>、$& 等替换写法。
- 配置页支持中英双语，默认跟随浏览器语言。

权限与隐私
- 页面内标识和标题改写需要「访问所有网站」的权限：Firefox 可在配置页内申请 / 取消，Edge / Chrome 在扩展详情页的「站点访问权限」里管理。
- 没有任何网络请求，不上传数据，无统计 / 遥测；配置只保存在本机。
