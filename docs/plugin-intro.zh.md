# TabPilot 插件简介

TabPilot 是一个本地标签页管理器，支持 Firefox、Chrome 和 Edge。用统一的 URL 规则自动归组、上色、显示页面标识和改写标题，无网络请求、不上传数据。

## 主要功能

- 自动归组：按规则顺序匹配网址，设置名称、颜色和折叠状态，支持同一窗口的数量阈值。
- 规则管理：可视化两栏设置页，支持启停单条规则、复制、拖拽排序，以及从当前窗口的手动分组生成规则草稿。
- 页面内标识：可选彩色边框和分组名 banner，快速区分开发、测试和生产环境。
- 标题改写：按首条命中正则替换标题，支持捕获组重排和前缀、多行测试及测试文本保存；页面改名后自动重试。
- 图标操作面板：打开 popup 执行配置的同步/折叠动作，结果默认显示 3 秒后淡出关闭，并提供设置入口。
- 分组置前：可选按“固定标签 → 分组 → 游离标签”整理窗口，保持组成员和相对顺序。
- 拖入补规则：手动将网站拖入已有规则的组后，可确认、编辑并追加网站匹配地址；纯手动组不提示。
- 严格模式：可选将导航到当前规则范围外的 HTTP/HTTPS 页面移出组。
- 配置迁移：JSON 导出、整份替换导入、仅追加规则的追加导入；追加时保留当前全局设置，自动处理重名和 id 冲突。
- 中英双语：设置页和 popup 支持中文 / English，默认跟随浏览器语言。

## 规则与设置

一条规则对应一个分组，多条匹配路径任一命中即可。顺序即优先级，匹配路径支持 localhost 等简写并自动补全。复制和从窗口生成仅修改草稿，保存同步后生效；追加导入经确认后直接保存同步。

全局配置有语言、图标行为和四个功能开关，采用两列卡片。自动更新分组规则与操作结果提示默认开启，分组置前与严格模式默认关闭。扩展内全局启停已移除，每条规则仍可单独停用。

## 权限与隐私

页面标识和标题改写使用 HTTP/HTTPS 内容脚本：Firefox 在设置页申请 / 撤销站点访问权限，Chrome / Edge 在浏览器扩展详情页管理。图标 popup 不依赖网页脚本或系统通知；Firefox 的图标右键“选项”入口使用 menus 权限。

拖入后自动打开 popup 需要 Firefox 149+ / Chromium 127+，旧版或打开失败时显示角标，点击图标即可处理。基本功能支持 Firefox 140+ / Chromium 116+。

无网络请求、数据上传、统计或遥测。配置和待确认项保存在本机，日志仅在内存与控制台。当前源码功能及各浏览器验收状态见 [开发计划](development-plan.md)，本简介不代表商店发布状态。
